# Student Performance Analysis

## Project Overview
This project explores student performance in Mathematics, Reading, and Writing using Python and statistical analysis.

The objective is to clean the dataset, investigate relationships between student characteristics and examination scores, and communicate findings through statistical summaries and visualizations.

## Dataset Source
**Dataset:** Students Performance in Exams

**Author:** Jakki Seshapanpu

**Source:** Kaggle

**URL:** https://www.kaggle.com/datasets/spscientist/students-performance-in-exams

The original dataset contains 1,000 student records and 8 attributes.

A separate modified copy was created for educational data-cleaning practice by introducing missing values, duplicate records, inconsistent categories, and invalid score values.

## Analysis Performed
1. Dataset loading and quality auditing.
2. Data cleaning and preprocessing.
3. Feature engineering.
4. Descriptive statistical analysis.
5. Gender-based performance comparison.
6. Correlation analysis between examination scores.
7. Welch's independent t-tests.
8. Cohen's d effect size and Bonferroni correction.
9. Data visualization and interpretation.

## Visualizations
- Bar chart: Mean subject scores by gender.
- Scatter plot: Reading versus Writing scores.
- Heatmap: Pearson correlation between subject scores.
